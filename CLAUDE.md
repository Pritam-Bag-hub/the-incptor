# Project Instructions

## Main Product Requirements

The complete product requirements are located at:

docs/PRD.md

This document is the main source of truth for the AgriContract AI project.

## Before Making Changes

1. Read docs/PRD.md before implementing features.
2. Inspect the existing codebase completely before modifying it.
3. Understand the current frontend, routes, components, and architecture.
4. Do not delete or rebuild working functionality unnecessarily.
5. Reuse existing components where possible.

## Development Rules

1. Implement features incrementally.
2. Do not implement all 47 PRD sections at once.
3. Follow the implementation phases defined in docs/PRD.md.
4. Keep frontend, backend, database, and AI logic separated.
5. Never expose API keys in frontend code.
6. Validate important business logic on the backend.
7. Use rule-based logic where actual machine learning is not yet implemented.
8. Do not generate fake AI scores or fake production data unless clearly marked as demo data.
9. Test the application after significant changes.
10. Keep the code modular and organized.

## Current Task

Before writing new features, perform a complete audit of the existing repository.

Create a report containing:

- Current technology stack
- Existing pages and routes
- Existing components
- Existing backend or API functionality
- Existing database integration
- Existing authentication
- Features already implemented from docs/PRD.md
- Missing features
- Recommended implementation order

Do not modify existing code during the audit.
